# HERO ISLANDS 12 — 3D Superhero Tycoon Arena

**Версия 2.0 — отдельная расширенная сборка проекта HERO ISLANDS.** Браузерная онлайн-игра с собственной 3D-картой, городом, двенадцатью базами и супергероями. Герои и костюмы **оригинальные**, не являются персонажами Marvel.

## Что реализовано

- 3D-остров и море, большой процедурный город NEXUS TOWER с высотками, светящимися окнами, улицами, деревьями и уличными фонарями.
- 12 отдельных баз по кругу острова; один игрок занимает одну базу. До **12 реальных подключённых игроков в одной комнате**.
- 12 различных супергероев с уникальным оружием, скоростью, запасом здоровья и суперспособностями.
- PvP через сервер Socket.IO: выстрелы, попадания, уничтожение, начисление награды и возрождение.
- 8 боевых NPC-дронов для тренировки даже без других игроков; за уничтожение начисляются кредиты.
- Tycoon-механика: пассивный доход каждые 4 секунды, улучшения генератора, турелей и силового купола.
- Турели второго уровня автоматически обороняют базу от игроков. Интерфейс: здоровье, энергия, экономика, навыки, таблица лидеров, мини-карта, события.
- Отдельные комнаты по коду, автоматическое заполнение общих комнат PUBLIC.
- Клавиатура/мышь; базовые сенсорные кнопки для мобильного браузера.

## Запуск на Windows (необходимы Node.js 20+ и интернет для установки пакетов)

1. Распакуй ZIP в любую папку.
2. Открой терминал в папке с `package.json`.
3. Введи:

```bash
npm install
npm run dev
```

4. Открой **http://localhost:5173**.

Или дважды кликни **START_WINDOWS.bat**: он устанавливает зависимости, собирает проект и запускает игру на http://localhost:3001.

### Как проверить настоящую игру на 2-12 игроков

Открой ту же ссылку в двух разных браузерах или на двух компьютерах, доступных к одному серверу. В обоих выбери одинаковый код комнаты (например `TEST123`), разных героев и нажми «НАЧАТЬ ИГРУ». Все участники должны быть подключены к **одному** серверу Node.js.

В локальной сети: собери проект (`npm run build`), запусти сервер (`npm start`) и открой `http://IP_КОМПЬЮТЕРА:3001` на другом устройстве. Возможно, потребуется разрешение в брандмауэре Windows.

## Управление

| Действие | Клавиша |
|---|---|
| Двигаться | WASD |
| Осматриваться | Мышь после клика по игре |
| Атака | ЛКМ (удерживание) |
| Суперспособность | E |
| Бег | Shift |
| Улучшение базы рядом с ней | B |
| Изменить дистанцию камеры | Колёсико мыши |
| Выключить/включить эффекты звука | M |
| Вернуться в меню | Кнопка «ВЫХОД» |

**Важное:** возрождение происходит автоматически; игрок получает базу по свободному слоту, а уникальный герой автоматически заменяется на свободного, если выбранный уже занят.

## Продакшен: один Node.js-сервер + статика

```bash
npm install
npm run build
npm start
```

Адрес: **http://localhost:3001**. Если хостинг предоставляет переменную `PORT`, приложение использует её. Для публикации полного мультиплеера нужен хостинг **Node.js с поддержкой WebSocket** (например, подходящая конфигурация Render/Railway/VPS). **Один Cloudflare Pages не запустит этот Socket.IO-сервер.**

## Технические ограничения текущей версии

- Состояние комнат хранится в памяти сервера. Оно сбрасывается при перезапуске — база, монеты и рекорды пока **не сохраняются в БД**.
- Нет аккаунтов, чата, платежей, подбора игроков по рейтингу, античита уровня коммерческой игры и графики уровня крупной студии.
- Сервер проверяет базовые скорости движения и частоту атак, но для публичного конкурентного запуска нужна более строгая серверная авторитетность, логирование и защита от злоупотреблений.
- В данном архиве лежат **исходники**. Для запуска требуется `npm install`; готовый `node_modules` не включён.
- 12 игроков — **максимальная вместимость** одной комнаты, не 12 подключённых ботов. 8 тренировочных дронов — отдельные NPC.

## Команды разработчика

- `npm run dev` — Node-сервер (3001) и Vite (5173) вместе.
- `npm run build` — клиент в `dist/`.
- `npm start` — сервер Socket.IO и собранный сайт на `PORT` или 3001.
- `npm run check` — проверка синтаксиса JavaScript.
- `node --test tests/shared.test.js` — тест игровых констант.

Файлы используют Three.js и Socket.IO. Весь арт генерируется программно — не требуются внешние 3D-модели или изображения. Внешние Google Fonts факультативны, при их недоступности используется системный шрифт.
