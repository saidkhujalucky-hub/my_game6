# Как проверить HERO ISLANDS 12

Эти проверки выполняются **после установки зависимостей**. Сборка в этом архиве была проверена на синтаксис и тесты общих конфигураций, но не на полноценный запуск мультиплеера в браузере.

1. `npm install` — успешно устанавливаются пакеты.
2. `npm run dev` — терминал показывает работающие процессы Vite и сервера.
3. Открой `http://localhost:5173` — в меню 12 героев, индикатор сервера зеленый.
4. Нажми «Начать игру» — появятся 3D-город, мини-карта, интерфейс с 180 кредитами.
5. Зажми WASD, поверни мышь, нажми ЛКМ — персонаж двигается и стреляет.
6. В центре города найди оранжевых дронов, попади по ним — уменьшается здоровье, за уничтожение начисляется +45 кредитов.
7. Нажми `E` — применяется способность героя; при достаточной энергии начинается перезарядка.
8. На своей базе нажми `B` — уровень 1 покупается за 120 кредитов, уровень 2 за 260, уровень 3 за 480.
9. Открой вторую вкладку в отдельном браузере, зайди в ту же комнату с другим ником и героем — оба игрока видны друг другу. Повторить с несколькими клиентами.
10. Для закрытой комнаты введи одинаковый код `TEST12` в обоих браузерах; другой код изолирует игроков.
11. При входе с уже занятым героем сервер выбирает другого свободного персонажа.
12. После попаданий до 0 HP начинается таймер возрождения, персонаж возвращается на свою базу.

Для настоящего онлайна **вне локальной сети** сначала опубликуй Node.js-сервер и открой сайт по его адресу. Хостинг статических файлов без Socket.IO-бэкенда сам по себе не обеспечит сетевую игру.
