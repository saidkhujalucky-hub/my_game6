# HERO ISLANDS 3.0 — Cloudflare Native Online

В версии 3.0 игровой сервер встроен в Cloudflare Worker. Node.js / Render не требуется.

## Публикация
1. GitHub: репозиторий `saidkhujalucky-hub/my_game6`, ветка `main`.
2. Cloudflare Workers & Pages → существующий Worker `my-game6` → Git Integration, production `main`.
3. Сборка: `npm run build` (если есть отдельное поле), публикация: `npx wrangler deploy`. Если сборку отдельно не настроить, `postinstall` запускает Vite при установке зависимостей.
4. Конфигурация `wrangler.jsonc`: статика `dist`, код Worker `worker.js`, Durable Object `ARENA`.
5. Адрес сайта: https://my-game6.saidkhujalucky.workers.dev
6. После успешной публикации проверь `/health` (JSON с `ok: true`), затем попробуй зайти в матч из двух разных браузеров/вкладок в одной комнате.

## Новая версия
- 12 оригинальных супергероев, детализированные процедурные 3D-костюмы и вращающийся предпросмотр;
- 12 баз и до 12 игроков в одной комнате; публичные и комнаты по коду;
- 8 дронов, PvP, способности, доход, турели, 3 улучшения базы, возрождение;
- серверная авторитетная обработка попаданий и денег.

## Ограничения
- Графика зависит от видеокарты и WebGL.
- Матчи в памяти Durable Object могут сбрасываться при перезапуске экземпляра Cloudflare.
- Для долговременной игры и многих комнат учитывай квоты тарифного плана Cloudflare.
- Автоматические тесты не заменяют реальную проверку двух браузеров.
